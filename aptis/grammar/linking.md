# Linking: so, so that, even when, even if

> **Chốt**
> **so** = vì vậy (kết quả). **so that** = để mà (mục đích), thường + *can / could / will / would*.
> **even when** = ngay cả lúc việc **thật sự xảy ra**. **even if** = ngay cả **nếu** (giả định).
> Aptis Writing: mục đích → *so that*, đừng viết *so more people know*.

## 1. so = vì vậy (kết quả)

Nối nguyên nhân → kết quả. *so = therefore = as a result*.

**S + V, so + S + V**

- *I was tired, **so** I went to bed.*
- *It was raining, **so** we stayed at home.*
- *The road was busy, **so** we arrived late.*

## 2. so that = để mà (mục đích)

Không phải kết quả. Thường có modal.

**S + V + … so that + S + modal + V**

- *I study hard **so that I can pass** the exam.*
- *We left early **so that we wouldn't miss** the bus.*
- *She speaks slowly **so that everyone can understand** her.*

*so that* ≈ *in order that*. *so that* tự nhiên hơn khi nói / viết email.

- *I exercise every day **so that** I can stay healthy.*

## 3. so vs so that — phân biệt nhanh

**so** = kết quả: *It was cold, **so** I wore a jacket.* (Trời lạnh → **nên** mặc áo.)

**so that** = mục đích: *I wore a jacket **so that** I wouldn't feel cold.* (Mặc áo **để** không lạnh.)

## 4. Email Aptis

❌ *We should advertise the event on social media **so** more people know about it.*

✅ *We should advertise the event on social media **so that more people can learn about it**.*
(xem [[prepositions]] cho *on social media*)

Hoặc tách câu kết quả:

- *We should advertise the event on social media. **As a result**, more people will know about it.*

## 5. so + adjective — nghĩa thứ ba

*so + tính từ / trạng từ* = **rất, quá**. Đừng nhầm với *so* kết quả.

- *The movie was **so interesting**.* / *It is **so expensive**.*

**so + adj + that + clause** = đến nỗi

- *The book was **so interesting that** I finished it in one day.*
- *He was **so tired that** he fell asleep immediately.*

| Cấu trúc | Nghĩa | Ví dụ |
|---|---|---|
| **so + S + V** | vì vậy (kết quả) | *I was tired, **so** I slept.* |
| **so that + S + modal + V** | để mà (mục đích) | *I slept early **so that** I could wake up early.* |
| **so + adj/adv** | rất, quá | *It is **so** beautiful.* |
| **so + adj + that** | đến nỗi | *It was **so cold that** we stayed inside.* |

## 6. even when

Việc đó diễn ra thật. Nối ý rất tự nhiên khi nói.

**Even when + mệnh đề, mệnh đề chính.**

- *I listen to music even when I study.*
- *We still spend time together even when we're busy.*

## 7. even if

Giả định hoặc không chắc chắn.

- *I'll support you even if you fail.*
- *We still spend time together even if we're busy.*

## 8. even when vs even if vs even though

- *I go running **even when** it rains.* → trời **đang / thường** mưa, vẫn chạy.
- *I would go running **even if** it rained.* → **giả sử** mưa, vẫn chạy.
- *Even though I was tired, I finished the work.* → **mặc dù** (sự thật), gần *although*.

Speaking: đang giả định thì **even if** rõ hơn.

| Cụm | Nghĩa |
|---|---|
| even **when** | ngay cả lúc (việc xảy ra thật) |
| even **if** | ngay cả nếu (giả định) |
| even **though** | mặc dù (sự thật) |
