# Phrases

From chats with lyn. Learn the whole chunk, not one word.

## 2026-08-26

### make a mistake
Not: have a mistake
- If I make a mistake, just tell me.

### I'm + -ing
Not: I typing
- When I'm typing with you, please correct me.

### one more thing / also
Not: an extra info (`information` has no `an`)
- One more thing: Vietnamese is my mother tongue.

### mother tongue
Not: mother tonge
- Vietnamese is my mother tongue.

### message / text (noun)
`texting` = the activity. A `message` = the words.
- Please fix my messages first.

### I've been meaning to + verb
I wanted to do this for a while, but I still haven't. (tôi định... từ lâu rồi, nhưng chưa làm)
- I've been meaning to talk to you about tomorrow's meeting.
- I've been meaning to hang out with you.

See [[present-perfect]].

### talk to someone about something
Not: discuss with you about
- Can I talk to you about something?

### discuss something with someone
No `about`. A bit more formal.
- We need to discuss the budget with the team.

### tomorrow's meeting
Not: the tomorrow's meeting

### hang out with someone
đi chơi / ngồi chơi với ai
- Do you want to hang out this weekend?

### really like / like ... a lot
Not: very like
- I really like this idea.
- I like this idea a lot.

### if you're free / if that's convenient for you
A person is not convenient. A time is convenient **for** you.
- We can discuss it tomorrow if you're free.

### something came up
có việc đột xuất. Not: something came up with me / an unexpected trouble
- Hey, can we cancel dinner tonight? Something came up.

### cancel / reschedule
`pause` = a video or a subscription. Plans: cancel or reschedule.

### If I had..., I would...
Not true now.
- If I had more time, I would spend it all learning languages.

See [[conditionals]].

### spend time / spend it + -ing
- I spend a lot of time watching films.

### look something up
tra cứu — a fact, Google, a dictionary
- I'll look it up.

### look into something
tìm hiểu / xem xét — a problem, takes time
See also [[look]].
- I'll look into it.
